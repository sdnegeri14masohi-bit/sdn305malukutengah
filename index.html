Profil SDN 305 Maluku Tengah

SDN 305 Maluku Tengah merupakan salah satu satuan pendidikan dasar unggulan yang berdedikasi tinggi di wilayah Kabupaten Maluku Tengah.

Dengan menerapkan kurikulum pembelajaran terkini, kami berfokus tidak hanya pada pencapaian akademik siswa, tetapi juga pada pembentukan karakter religius, disiplin, gotong royong, serta pemahaman budaya lokal daerah Maluku.

"Terwujudnya Peserta Didik yang Berakhlak Mulia, Cerdas, Terampil, Berprestasi, dan Peduli Lingkungan Berdasarkan Iman dan Taqwa."

Misi Sekolah

  • Menanamkan nilai spiritual dan akhlak mulia dalam kehidupan sehari-hari.
  • Melaksanakan proses pembelajaran yang aktif, kreatif, efektif, dan menyenangkan.
  • Meningkatkan keterampilan siswa dalam pemanfaatan teknologi informasi.
  • Membangun kolaborasi erat antara sekolah, orang tua, dan masyarakat lokal Maluku Tengah.

1

Buat Akun GitHub

Daftar akun gratis di github.com jika belum punya.

2

Buat Repository

Klik tombol "New Repository". Beri nama misal: sdn305malteng. Pilih Public.

3

Upload File

Simpan seluruh kode website ini dengan nama index.html. Upload file tersebut ke repository baru tadi.

4

Aktifkan Pages

Masuk ke menu Settings > Pages. Pilih Branch ke main / master, lalu klik Save.

5

Website Live!

Tunggu 1-2 menit. Website Anda siap diakses di alamat: username.github.io/sdn305malteng
